= ESP32-Based 8-Relay Control System via Google Home

This project presents the design and implementation of an IoT-based smart home control system using an ESP32 microcontroller.  
The system allows users to control eight independent relay channels through Google Home voice commands via the Internet.

The project is developed as *Project 2* and focuses on practical IoT deployment, including network connectivity, cloud integration, remote device control, and firmware maintainability.

Key objectives of the project include:
- Designing a stable ESP32-based control system
- Integrating Google Home for voice-based control
- Implementing WiFi configuration through a captive portal
- Supporting Over-The-Air (OTA) firmware updates
- Controlling multiple electrical loads safely and reliably

== System Overview

The ESP32 serves as the central controller of the system. After connecting to a WiFi network, it communicates with cloud services that interface with Google Home.  
Each relay channel is represented as a virtual smart device, enabling individual or grouped control via voice commands or mobile applications.

Main functional modules of the system include:
- WiFi configuration and network management
- Google Home cloud integration
- Eight-channel relay control logic
- OTA firmware update mechanism
- Embedded web server for configuration and monitoring
- System recovery and reliability handling

== Step 1: Installation and Environment Setup

1. Clone or download this repository to your local computer.
2. Open the project using the Arduino IDE.
3. Install the ESP32 board package via the Board Manager.
4. Install all required libraries specified in the source files.
5. Compile the project to ensure that the development environment is correctly configured.

== Step 2: Hardware Assembly

Assemble the hardware components according to the provided design documentation:

Required components:
- ESP32 development board
- 8-channel relay module
- External power supply (5V / 3.3V as required)

Refer to the following files for guidance:
- `schematics.png`: Logical circuit schematic
- `layout.png`: Physical wiring layout

Make sure to properly isolate the low-voltage ESP32 circuitry from high-voltage relay loads to ensure safety.

== Step 3: WiFi Configuration

On first startup, the ESP32 enters WiFi configuration mode:

1. Connect to the temporary WiFi access point created by the ESP32.
2. Open a web browser and navigate to the configuration page.
3. Enter the target WiFi SSID and password.
4. Save the settings and reboot the device.

Once configured, the ESP32 will automatically reconnect to the saved network on subsequent startups.

== Step 4: Firmware Upload and OTA Update

The system supports Over-The-Air (OTA) firmware updates:

1. Ensure the ESP32 and the development computer are on the same network.
2. Upload new firmware wirelessly using the configured OTA service.
3. Monitor the update process via the Serial Monitor or web interface.

This feature allows firmware updates without physical access to the device, improving maintainability.

== Step 5: Google Home Control

After successful network connection and cloud registration:
- Each relay channel appears as a controllable smart device in Google Home.
- Users can turn individual relays ON or OFF using voice commands.
- Multiple relays can be grouped and controlled simultaneously.

This enables intuitive and hands-free control of connected electrical devices.
