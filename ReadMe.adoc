= Project: ESP32-Based 8-Relay Control System via Google Home

This project implements an IoT-based home automation system using an ESP32 microcontroller to control eight relay channels through Google Home voice commands.

The system enables users to remotely control electrical devices via the Internet, providing a practical demonstration of smart home technologies.  
Key features include WiFi configuration through a captive portal, over-the-air (OTA) firmware updates, and seamless integration with Google Home for voice control.

The project is developed as *Project 2* and focuses on system integration, network connectivity, and real-time device control.

A full demonstration of the system is available in the following video:

*Video demo:* https://youtu.be/fp8oZTBzxIA

== System Overview

The ESP32 acts as the central controller, connecting to a WiFi network and communicating with cloud services that interface with Google Home.  
Each relay channel is mapped to a virtual smart device, allowing independent on/off control via voice commands or mobile applications.

Main functional modules:
- WiFi configuration and network management
- Google Home integration
- Relay control logic (8 channels)
- OTA firmware update
- System monitoring and recovery

== Step 1: Installation and Setup

1. Clone or download this repository to your local machine.
2. Open the project using the Arduino IDE or PlatformIO.
3. Install the required ESP32 board package and libraries.
4. Compile the project to verify that all dependencies are correctly installed.

== Step 2: Assemble the hardware

Assemble the hardware according to the provided schematics and layout:

- ESP32 development board
- 8-channel relay module
- External power supply (if required)

Refer to:
- `schematics.png` for logical connections
- `layout.png` for physical wiring guidance

Ensure correct power isolation between the ESP32 and high-voltage relay loads.

== Step 3: WiFi configuration

At first boot, the ESP32 starts in WiFi configuration mode:

1. Connect to the temporary WiFi access point created by the ESP32.
2. Open the configuration web page.
3. Enter the target WiFi SSID and password.
4. Save the configuration and reboot the system.

The device will automatically reconnect to the configured network on subsequent boots.

== Step 4: Upload and update firmware (OTA)

The system supports Over-The-Air updates:

1. Connect the ESP32 to the same network as your computer.
2. Upload new firmware wirelessly using the configured OTA service.
3. Monitor update progress via the Serial Monitor or web interface.

This allows firmware upgrades without physical access to the device.

== Step 5: Google Home control

After successful network connection:
- Each relay is registered as a controllable smart device.
- Relays can be switched on or off using Google Home voice commands.
- The system supports individual and group control of relay channels.
